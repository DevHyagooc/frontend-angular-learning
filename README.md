# Frontend Angular Learning

Repositório dedicado à minha jornada de aprendizado em **desenvolvimento Frontend com foco em Angular**.

Atualmente atuo como **QA Pleno** e estou expandindo meus conhecimentos para desenvolvimento Frontend, com o objetivo de construir uma base sólida e alcançar autonomia suficiente para atuar futuramente como **Desenvolvedor Frontend Angular Júnior**.

Este repositório será utilizado para registrar exercícios, desafios, projetos e minha evolução durante os estudos.

---

## Objetivo

O objetivo desta jornada não é apenas aprender a sintaxe do Angular, mas desenvolver capacidade para:

- compreender e decompor problemas;
- construir interfaces utilizando HTML e CSS;
- programar com JavaScript e TypeScript;
- desenvolver aplicações Angular;
- criar e reutilizar componentes;
- trabalhar com Services e Dependency Injection;
- consumir APIs REST;
- implementar rotas e formulários;
- trabalhar com RxJS e Signals;
- testar aplicações frontend;
- investigar e corrigir problemas;
- utilizar Git no fluxo de desenvolvimento;
- pesquisar documentação;
- explicar decisões técnicas;
- utilizar Inteligência Artificial como ferramenta de apoio sem substituir o raciocínio.

---

## Metodologia

O aprendizado seguirá um processo progressivo:

**Teoria → Exemplo → Exercício → Implementação → Revisão → Desafio → Projeto**

Durante os estudos, a prioridade será desenvolver autonomia.

A Inteligência Artificial será utilizada principalmente para:

- explicações;
- pistas;
- revisão de código;
- debugging;
- geração de exercícios;
- comparação de abordagens;
- code review;
- apoio na leitura de documentação.

Evito utilizar IA para simplesmente gerar funcionalidades completas ou soluções que eu não consiga explicar posteriormente.

## Projetos

Durante a jornada serão desenvolvidos projetos progressivos.

### Projeto Web Fundamental

Aplicação utilizando HTML, CSS e JavaScript sem frameworks.

### Primeira aplicação Angular

Projeto focado nos fundamentos do framework e componentização.

### CRUD Angular

Aplicação integrada a uma API REST contendo listagem, criação, edição, exclusão e consulta de dados.

### Aplicação Angular Intermediária

Projeto combinando recursos como Router, Reactive Forms, autenticação, RxJS, Services e componentes reutilizáveis.

### Projeto Final — Portal de Seguros

Aplicação corporativa fictícia desenvolvida para consolidar os principais conhecimentos adquiridos durante a jornada.

O projeto será construído através de pequenas tarefas, simulando um fluxo de desenvolvimento profissional.
