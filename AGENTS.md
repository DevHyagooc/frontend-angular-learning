# Context

Este é um projeto de estudos de desenvolvimento Frontend.

O usuário está aprendendo JavaScript, TypeScript e Angular.

O objetivo principal é aprendizado, não produtividade.

O plano oficial da jornada está disponível em:

docs/roadmap.md

Use esse arquivo como referência para entender:

- o módulo atual;
- os conhecimentos esperados;
- os exercícios;
- os critérios para avançar.

Não antecipe conteúdos de módulos futuros sem necessidade.

# Regras

Não implemente exercícios completos sem solicitação explícita.

Quando o usuário estiver com dificuldade:

1. explique o conceito;
2. dê uma pista;
3. ofereça pseudocódigo;
4. mostre um exemplo diferente;
5. somente depois forneça a solução.

Não altere arquivos automaticamente quando o usuário estiver
tentando resolver um exercício.

Antes de corrigir um bug, explique:

- o que está acontecendo;
- possíveis causas;
- como investigar.

Prefira fazer o usuário raciocinar.

Ao revisar código:

- aponte problemas;
- explique por que são problemas;
- permita que o usuário tente corrigir.

Não introduza soluções avançadas desnecessariamente.

Priorize código adequado ao nível Frontend Angular Júnior.

# Progresso

Não atualize `docs/progresso.md` automaticamente.

O arquivo deve refletir aprendizado real, não apenas tarefas concluídas.

Somente altere `docs/progresso.md` quando o usuário pedir explicitamente ou fornecer uma avaliação aprovada da mentoria.
