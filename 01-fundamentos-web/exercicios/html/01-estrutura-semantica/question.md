Exercício 01 — Refatoração semântica
Fácil
Assunto: HTML — Estrutura e semântica.

Contexto
Imagine que você recebeu o seguinte HTML de outro desenvolvedor:

<div class="topo">
  <div>Portal de Serviços</div>
</div>

<div class="menu">
  <span>Início</span>
  <span>Chamados</span>
</div>

<div class="conteudo">
  <div>Chamados recentes</div>
  <div>Nenhum chamado encontrado.</div>
</div>


O código não está necessariamente inválido, mas pode melhorar semanticamente.
Sua tarefa
Refatorar essa estrutura utilizando HTML semântico.

Critérios de aceite:
1. Criar um documento HTML completo, com DOCTYPE, html, head e body.
2. Substituir os elementos genéricos quando existir uma alternativa semântica mais apropriada.
3. Representar os itens de navegação como links reais, utilizando destinos fictícios.
4. Utilizar títulos com hierarquia coerente.
5. Não adicionar CSS nem JavaScript nesta atividade.
