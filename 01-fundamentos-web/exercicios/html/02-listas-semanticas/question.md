Exercício 02 — Listas semânticas
Fácil

Sua tarefa
Crie uma página HTML chamada Central de Treinamentos contendo três áreas:
1. Um cabeçalho com o nome da página.
2. Uma navegação com três links fictícios: Início, Cursos e Certificados.
3. Um conteúdo principal contendo:
   - Uma lista com três cursos disponíveis, cuja ordem não é importante.
   - Uma lista com três etapas que o usuário deve seguir para concluir um treinamento, cuja ordem é importante.
Critérios de aceite: documento HTML completo, elementos semânticos apropriados, utilização consciente de ul, ol e li, links representados por a e ausência de CSS e JavaScript.
Perguntas de compreensão
Responda em comentários no index.html:
1. Qual é a diferença entre <ul> e <ol>?
2. Por que é melhor representar um conjunto de cursos utilizando elementos de lista em vez de vários <div>?
3. Um menu dentro de <nav> precisa obrigatoriamente utilizar <ul>? Justifique.
