8. Exercício 03 — Formulário de solicitação de suporte
Fácil
Vamos aplicar esses conceitos em uma situação próxima de um sistema corporativo.

Contexto
Você recebeu uma tarefa para implementar a interface inicial de um formulário de solicitação de suporte.

O usuário deverá fornecer algumas informações para abrir uma solicitação.
Critérios de aceite
1. Criar um documento HTML completo.
2. Utilizar elementos semânticos adequados, incluindo header e main.
3. Criar um formulário com três campos: nome completo, e-mail e assunto da solicitação.
4. Utilizar os tipos text e email adequadamente.
5. Associar corretamente um <label> a cada campo.
6. Adicionar os atributos id e name aos inputs.
7. Tornar os campos nome e e-mail obrigatórios.
8. Adicionar um botão para enviar o formulário utilizando o tipo apropriado.
9. Não utilizar CSS nem JavaScript.
Não é necessário integrar uma API nem realmente enviar uma solicitação.

Perguntas de compreensão
Responda como comentários HTML no index.html, conforme nosso padrão:
1. Qual é a diferença entre os atributos id e name de um input?
2. O que acontece quando o atributo for de um label não corresponde ao id do campo?
3. Qual é a diferença entre type="button" e type="submit"?
4. Por que não podemos depender exclusivamente do atributo required para validar dados enviados a uma API?
